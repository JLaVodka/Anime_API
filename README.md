# Anime-API
Aplicación móvil desarrollada con Expo y React Native que centraliza consultas a dos fuentes de datos: una base de datos propia alojada en Supabase (PostgreSQL) y la API pública de PokeAPI, integrando ambas en una única experiencia de cliente.

## Características
Consultas a datos propios almacenados en Supabase (PostgreSQL)
Integración con la API pública de PokeAPI
Unificación de ambas fuentes de datos en una sola interfaz de usuario
Desarrollado con Expo, lo que facilita probar la app en dispositivos reales mediante Expo Go

## Tecnologías
Expo, React Native, JavaScript, PostgreSQL (Supabase)
